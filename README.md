# 논알콜 판매 대시보드

네이버 스마트스토어 + 쿠팡 로켓그로스 논알콜 음료 판매 현황 대시보드

## GitHub Pages 배포 방법

### 1단계 — 이 파일들을 GitHub에 올리기

1. [github.com](https://github.com) 접속 → 로그인
2. 우상단 `+` → **New repository**
3. Repository name: `nonalcohol-dashboard` (원하는 이름)
4. **Public** 선택 (무료 Pages 사용)
5. **Create repository** 클릭
6. `index.html`, `README.md` 두 파일을 **Add file → Upload files** 로 업로드
7. **Commit changes** 클릭

### 2단계 — GitHub Pages 켜기

1. 해당 레포지토리 → **Settings** 탭
2. 왼쪽 메뉴 **Pages** 클릭
3. Branch: `main` / Folder: `/ (root)` 선택 → **Save**
4. 약 1~2분 후 `https://{유저명}.github.io/{레포명}/` URL로 접속 가능

## 구글 시트 연동 방법

### 구글 시트 형식

마스터 데이터 시트를 아래 컬럼으로 만들어야 해요:

| 날짜 | channel | product | qty | note |
|------|---------|---------|-----|------|
| 2026-08-01 | 네이버 | 논알콜 12입(캔) | 168 | |
| 2026-08-01 | 네이버 | 논알콜 6입(캔) | 36 | |
| 2026-08-01 | 쿠팡 | 논알콜 6입(캔) | 192 | |

> **날짜 형식**: `YYYY-MM-DD` (예: 2026-08-01)  
> **note**: 재고이슈 등 특이사항 (비워도 됨)

### 구글 시트 공개 설정

1. 구글 시트 열기
2. 우상단 **공유** → **링크 있는 모든 사용자** → **뷰어** 설정
3. 주소창 URL 복사

### 대시보드에서 연결

1. 대시보드 상단 **구글 시트 연동** 칸에 URL 또는 시트 ID 붙여넣기
2. **연결** 버튼 클릭
3. 연결 성공 시 차트 자동 업데이트

> 연결 정보는 브라우저에 저장되어 다음에 접속해도 자동 연결됩니다

## 데이터 업데이트 방법

구글 시트에 행을 추가하고 대시보드에서 **연결** 버튼을 다시 누르면 즉시 반영됩니다.

또는 기존처럼 **엑셀 파일을 직접 업로드**해도 동작합니다.
